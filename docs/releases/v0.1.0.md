# mojo-tls v0.1.0

**Released:** 2026-11-12 · **Commit:** tag `v0.1.0` · **Previous:** first release

## What it does

TLS 1.3 and TLS 1.2, client and server, with X.509 certificate validation, in pure Mojo: no OpenSSL, no C library, no foreign calls beyond a few libc
functions. 16.7k lines under `src/tls/`. It is for Mojo programs that serve HTTPS or connect to TLS servers. Install with `pixi add mojo-tls` (channels in the README);
`examples/server.mojo` and `examples/client.mojo` are the quickstart.

## Highlights

- TLS 1.3 and 1.2 client and server that interoperate with openssl, Firefox, Chromium and Vivaldi: matrix of 187 cells, 176 PASS, 11 SKIP (policy), 0 FAIL.
- X.509 chain validation to the system roots or a PEM file, checked against x509-limbo (9748 cases, 9730 agree, the 18 others pinned with a reason) and 118 of 118 system roots.
- TLS 1.3 session resumption, client certificates, P-384 and x448 groups; TLS 1.2 only in its safe form (ECDHE, AEAD, extended master secret).
- Fast enough to serve: 3055 in-memory handshakes per second per core, records at 5.1 GB/s (AES-128-GCM seal) and 1.6 GB/s (ChaCha20-Poly1305).

## Changes

### Added
- First release: the whole library (sym, asym, x509, tls13, tls12, net), the examples, the conda recipe, CI, the shipped skill.

- A use-after-free in the TLS 1.3 record reader's buffer compaction (found by heaptide, latent natively; `docs/heap-grow.md`).

- Record open is 2.4x faster (AES-GCM) and 1.4x (ChaCha20-Poly1305): copies by one memcpy; total cycles of the record bench down 26% (docs/perf.md).

## Known limits

- No independent security audit. The timing test (`tests/ct.mojo`) is a statistical dudect check: on a loaded machine it can fail; the gate retries three times (on a busy box the P-256 scalar-mult row failed twice before passing).
- GitHub CI has not run: the repository has no remote yet; `scripts/ci.sh` is what it will run.
- Refused by policy: TLS below 1.2, CBC and RSA key exchange, TLS 1.2 without extended master secret, renegotiation, 0-RTT. Not implemented: DTLS, QUIC, OCSP, revocation, FFDHE, post-quantum groups.
- SHA-256 is software-only (0.51 GB/s); no SHA-NI path.
